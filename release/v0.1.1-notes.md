# Axiom 0.1.1

## New Features

- Provide an Intel Mac test archive with the CLI, graph engine, MCP, skills and offline Python dependencies.
- Include `SHA256SUMS` for all downloadable assets.

## Known Limitations

This release targets native macOS x86_64 testing. Its binaries are unsigned and not notarized. Use the version-specific bootstrap below; newer releases provide a one-line installer.

## Download and test on Intel Mac

Download `axiom-0.1.1-macos-x64.tar.gz` and `SHA256SUMS` from this release.
The archive includes CLI, daemon, engine, MCP 0.1.1, skills 0.1.1, CPython 3.13.15,
and the pinned offline Python dependency wheelhouse. No system Python is needed.

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing
tar -xzf axiom-0.1.1-macos-x64.tar.gz
cd axiom-0.1.1-macos-x64
sh runtime/bootstrap.sh install --release-set "$PWD" --dry-run
```

Review the plan, then use its approval digest:

```sh
sh runtime/bootstrap.sh install --release-set "$PWD" --apply --approve-digest <PLAN_DIGEST>
"$HOME/.local/bin/axiom-cli" version --all --json
```

Use `uninstall` with the same dry-run/apply flow for owned installation removal.
The archive uses the existing local candidate installer and development trust
metadata (`published: false` inside the channel). The GitHub release is published;
this flag means the payload is not a signed production update channel.
Gatekeeper handling for these unsigned/not-notarized binaries is an explicit user action.
