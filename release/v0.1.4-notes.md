# Axiom 0.1.4

## New Features

- Add `update.sh` and `update.ps1` to release downloads. They find an existing installation and run its update command; older installations upgrade through the verified installer. With nothing installed, they print the installation command.
- Stop with clear instructions when legacy environment overrides would select the wrong installation.

Full Changelog: [v0.1.3…v0.1.4](https://github.com/cognivex006/axiom-cli/compare/v0.1.3...v0.1.4)

## Installation

Install the CLI, graph engine, MCP runtime and skills bundle for your user account. The scripts verify this release's archive SHA-256 before extraction; installation shows its plan and asks once.

Windows (PowerShell 5.1+):

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/cognivex006/axiom-cli/releases/download/v0.1.4/install.ps1 | iex"
```

macOS Intel, Linux x64 and WSL2:

```sh
curl -fsSL https://github.com/cognivex006/axiom-cli/releases/download/v0.1.4/install.sh | sh
```

## Update

Run `axiom-cli update`, or use the release's update script:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/cognivex006/axiom-cli/releases/download/v0.1.4/update.ps1 | iex"
```

```sh
curl -fsSL https://github.com/cognivex006/axiom-cli/releases/download/v0.1.4/update.sh | sh
```

The script uses an existing installation's update command; recognized older layouts upgrade through the installer. With nothing installed, it prints the installation command. Check the reported installed/offered version and any refusal before assuming an upgrade succeeded.

## Commands and setup

Use `axiom-cli` to manage this release. `axiom` is the graph engine's separate operations CLI. Use `axiom-cli version`, `axiom-cli doctor` and `axiom-cli --help` to inspect the installation. `axiom-cli uninstall` retains user data.

`install` manages the complete pinned component set; it does not accept a component name. Project registration, MCP permissions and host plugin discovery need their own setup. See the [installation guide](https://github.com/cognivex006/axiom-cli/blob/main/docs/INSTALL.md) and [skills/plugin guide](https://github.com/cognivex006/axiom-skills/blob/main/marketplace-plugins/README.md).

Every release asset is listed in `SHA256SUMS`. `channel.json` pins archive downloads; use `download/<tag>` instead of `latest/download` to select a particular release. Apple silicon and Linux arm64 are unavailable through these scripts.
